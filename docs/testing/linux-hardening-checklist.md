# Linux hardening and hardware checklist

Run each row per device class; record date, kernel, cage version and result.

| ID | Check |
|---|---|
| H1 | Unit to cage to launcher to main boot chain; fullscreen and service-user decision. |
| H2 | Exit 86 is inactive (dead), not failed; normal service is active. |
| H3 | Display never blanks for 24 h; systemd-inhibit is only a regression check. |
| H4a | Touch corner tap opens the pin pad; record tap/cancel behavior. |
| H4b | Bundled keyboard reaches, types into and dismisses every deployed-site text surface. |
| H5 | 72-hour offline-video soak, RSS trend, loop count and visual black-frame check. |
| H6 | VT, zap, sleep, shortcut, dialog and edge escape-vector sweep. |
| H7 | Real-network egress/nav guard, DNS failure and captive-portal behavior. |
| H8 | Cold runbook install; snapshots, credential, mp4 and spool absence checks. |
| H9 | Promoted service user can read the credential, write the spool and reach /run/kiosk. |
| H10 | Pinch zoom does not scale the page; two-finger pan/scroll still works. |
| H11 | SIGSTOP cage, observe no self-recovery, then verify documented power-cycle recovery. |
